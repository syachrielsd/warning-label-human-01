A single-line safety warning label for every human being, written in exact printed-label language: it opens on the universal lie "I'm fine" (nine times a day), escalates through the side effect of crying at dog commercials, and lands the laugh in the last two words — texting an ex at 1:12 a.m. "about closure". The program writes that one line, 132 characters, to entry.txt.

## Run it

```sh
node main.ts
```
